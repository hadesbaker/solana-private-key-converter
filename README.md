# SOLANA KEYPAIR FILE PRIVATE KEY GENERATOR

## Usage

1. Copy your keypair file and paste it in the main directory of this repo.

2. Run
```bash
cargo build --release
```

3. Run
```bash
cargo run --release -- wallet.json
```

or whatever the name of your file is.
